# 从第 1 周到实习投递

本仓库是 **Week 01** 的代码与练习。后续周次是学习路线标记，并不代表相应项目已经实现。

| 周次 | 主题 | 可展示的成果 |
| --- | --- | --- |
| **01 · 当前仓库** | 单次调用、结构化输出、工具调用 | 学习任务 Agent 和测试 |
| 02 | 会话状态、重试、异常处理；用 Agents SDK 复刻 | 支持多轮对话的版本 |
| 03–04 | 检索、引用来源、拒答与评测 | 技术文档问答 Agent；第 4 周开始投递 |
| 05–06 | 工作流、权限、人工审批 | GitHub Issue 处理 Agent |
| 07–08 | 失败案例、延迟/成本、面试讲解 | 两个项目的演示与简历项目经历 |

投递时重点展示你**自己改过的功能、测试和失败案例**。本仓库提供起点；Day 5 的 `rename_task` 练习适合成为你的第一笔独立提交。
