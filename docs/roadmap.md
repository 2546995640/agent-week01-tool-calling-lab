# 8 周 Agent 开发与实习投递路线

适用条件：已有软件开发经验、每周约 20 小时。仓库提供每周任务、离线参考实现和两个作品原型；要求你亲手扩充数据、改代码并记录失败案例。**第 4 周开始投递。**

| 周次 | 学习任务 | 本仓库入口 | 你要交付的内容 |
| --- | --- | --- | --- |
| 01 | 单次调用、结构化输出、工具调用 | [Week 01](week01.md)、`study_agent/runner.py` | 自己新增一个工具和测试 |
| 02 | 会话状态、错误恢复、幂等性 | [Week 02](week02.md)、`study_agent/session.py` | 两轮对话讲解与防重复提交设计 |
| 03 | 文档切分、检索、标注问题集 | [Week 03](week03.md)、`projects/doc_qa/` | 自己的文档与失败案例 |
| 04 | 带来源的回答、评测、首次投递 | [Week 04](week04.md)、`projects/doc_qa/eval.py` | 项目演示、简历、第一批投递 |
| 05 | Issue 分类、手册检索、结构化草稿 | [Week 05](week05.md)、`projects/issue_triage/` | 扩充 Issue 样例与分诊结果 |
| 06 | 人工批准、日志、重复发布保护 | [Week 06](week06.md)、`DraftOutbox` | 审批边界说明和第二个项目演示 |
| 07 | 评测、错误分析与改进 | [Week 07](week07.md)、两个 `eval.py` | 独立案例集与改进记录 |
| 08 | 简历、面试、持续投递 | [Week 08](week08.md) | 两个作品的讲解和真实指标 |

[外部开源项目索引](open-source-projects.md)列出适合各阶段的官方或维护活跃的示例。它们是参考资料；本仓库中的虚构数据评测分数不能当作真实业务效果。
