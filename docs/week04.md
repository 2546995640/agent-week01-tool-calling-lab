# Week 04 · 文档问答、评测与第一次投递（20 小时）

| 时间 | 学习与动手 |
| ---: | --- |
| 5h | 阅读 `answer.py`，用真实模型时检查答案是否由检索段落支持；无密钥则继续做人工检索评测 |
| 4h | 把问题集扩到至少 30 条，分别报告检索 Hit@3、无依据拒答率和典型失败 |
| 4h | 补截图或录屏、架构图、启动步骤和限制说明 |
| 4h | 写简历项目经历，针对 5 个实习岗位微调关键词并开始投递 |
| 3h | 请同伴或我做一次代码与 README 评审，修复最影响展示的问题 |

作品应能让陌生人独立启动，看到一条有来源的结果，并理解评测数据从哪里来。**从本周开始投递**，无需等完整 8 周结束。

简历描述模板：

> 独立实现文档问答原型，完成 Markdown 切分、BM25 检索、来源引用与无依据拒答；构建 N 条人工标注问题集，记录 Hit@3 为 X%，分析并改进主要失败类型。

只有在你实际测得 N 和 X 后再填入数字。模型回答准确率需要另外人工标注，不能用检索 Hit@3 代替。
