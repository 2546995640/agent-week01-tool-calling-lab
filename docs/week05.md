# Week 05 · 多步骤工作流与工具权限（20 小时）

本周开始第二个作品：[Issue 分诊原型](../projects/issue_triage/README.md)。重点是把读取、判断、草稿和发布分成清晰步骤。

| 时间 | 学习与动手 |
| ---: | --- |
| 4h | 阅读 `triage.py`，画出每一步的数据输入和输出 |
| 5h | 添加 5 条新的虚构 Issue 和对应的手册内容 |
| 4h | 设计分类、优先级、证据与草稿的结构化输出字段 |
| 4h | 在 `cases.json` 标注预期结果，运行离线基线并分析错误 |
| 3h | 继续投递与岗位筛选，准备解释两个作品的差异 |

运行 `python -m projects.issue_triage 101`。完成标准：每个回复草稿都能指向可核查的手册依据；资料不足时能明确请求人工排查。
